# Integrating Peable

The integration guide is published at
**<https://oxy.so/developers/docs/peable/>**: the quickstart, payments on both
rails, Checkout, Payment Links, Elements, billing, Connect, tax, webhooks,
testing and the API conventions, with the API reference generated from
[`openapi.json`](openapi.json) and every error code.

Its source is [`packages/sdk/docs`](../packages/sdk/docs) (MDX, synced by the
Oxy website). Change the guide there, not here.
