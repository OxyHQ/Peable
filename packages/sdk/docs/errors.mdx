# Error codes

Every error Peable answers carries `error.type` — the broad class to branch on — and, when there is a more specific reason, `error.code`. `error.doc_url` links straight to that code below (`https://oxy.so/developers/docs/peable/errors/#resource_missing`). How to read and handle an error, in the API and in the SDK, is in [handling errors](/handling-errors).

## Error types

### Type `api_error`

Something went wrong on Peable or its provider (5xx, or 502 for a retryable provider fault). Safe to retry with the same `Idempotency-Key`.

### Type `authentication_error`

The credential is missing, expired or invalid (401).

### Type `card_error`

The payment method was declined (402). `decline_code` carries the issuer reason when there is one.

### Type `idempotency_error`

The `Idempotency-Key` was reused with a different request (400), or the first request with it is still running (409).

### Type `invalid_request_error`

The request is malformed, names something that does not exist, or conflicts with the state of an object (400, 404, 409).

### Type `permission_error`

The credential is valid but may not do this (403).

### Type `rate_limit_error`

Too many requests (429). Back off and retry.

## All codes

123 codes, alphabetically. A `card_error` can also carry the card network's own decline code, which is not listed here.

### `account_invalid`

The `Peable-Account` header names no connected account of this platform.

### `account_membership_required`

The signed-in Oxy account is not a member of the Oxy account the path names (a contribution route's organization).

### `account_missing`

The merchant has no account object yet.

### `account_not_ready`

The connected account cannot take this payment yet: its onboarding or a capability is incomplete.

The seller already confirmed FairCoin payments into their Peable wallet.

The tax settings cannot be approved yet: a legal name and head office are required, or they changed during the approval.

Registered sales need a tax provider, and this application has none: the approval would leave covered sales unpriceable.

### `card_declined`
