## Open a connected account

`POST /v1/connected_accounts`

Opens the account for one seller (201), or answers the one this `external_ref` already opened (200) — a provider account cannot be deleted, so a converged retry says so.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.connectedAccounts.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `external_ref` **required** | string | Your own id for the seller. Opening the same `external_ref` again answers that account (200). 1–255 characters. |
| `country` | string | The card half: ISO 3166-1 alpha-2 (case-insensitive). With `business_type`. Exactly 2 characters. |
| `business_type` | string | The card half: with `country`. One of `individual`, `company`. |
| `faircoin` | object | The FairCoin half (ADR 0012 D2): the chain the seller is paid on, and who they are. |
| `faircoin[network]` **required** | string | One of `mainnet`, `testnet`. |
| `faircoin[oxy_user_id]` **required** | string | The seller's Oxy user id — the only person who may register the key. 1–128 characters. |

**Response `201`**

Returns [ConnectedAccount](/reference/objects/connected-account).

## Create a seller's onboarding link

`POST /v1/connected_accounts/{accountId}/account_links`

Minted on demand and never stored: single-use and short-lived. A visit to `return_url` proves nothing about verification — read the account back.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.connectedAccounts.createAccountLink()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `accountId` **required** | path | string | The connected account (`ca_…`). |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `refresh_url` **required** | string (uri) | Where the seller goes when the link has expired. |
| `return_url` **required** | string (uri) | Where the seller returns when they leave the flow. |
| `rail` | string | Which half to onboard: `card` (the default) is the provider's hosted onboarding; `faircoin` is Peable's own page where the SELLER registers their watch-only key. |

**Response `201`**

Returns [AccountLink](/reference/objects/account-link).

```json

  "object": "account_link",
  "livemode": false,
  "url": "https://connect.peable.to/onboarding/Zk3s9v…",
  "expires_at": 1793750700
}
```
