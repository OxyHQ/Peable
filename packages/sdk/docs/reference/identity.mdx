## Create a verification session

`POST /v1/identity/verification_sessions`

Creates the session at the provider and answers its hosted `url` and `client_secret` — this answer and a retrieve are the only places they appear. 503 `identity_unavailable` when identity verification is not enabled in this mode.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.identity.verificationSessions.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `type` **required** | string | The check to perform. One of `document`, `id_number`. |
| `options` | object | `document` options apply to a `document` session only. |
| `options[document]` | object |  |

## Redact a verification session

`POST /v1/identity/verification_sessions/{id}/redact`
