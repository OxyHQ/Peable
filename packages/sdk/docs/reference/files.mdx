## Upload a file

`POST /v1/files`

The bytes as `multipart/form-data` (`purpose`, `file`), or — as JSON — `{ purpose, oxy_file }` to import an Oxy file you own. The type is recognised from the bytes, never from a `Content-Type`; each purpose has its own formats and size ceiling.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.files.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`multipart/form-data`)

| Field | Type | Description |
| --- | --- | --- |
| `purpose` **required** | string | One of `dispute_evidence`, `business_logo`, `identity_document`, `additional_verification`, `tax_document`. |
| `file` **required** | string (binary) | The bytes, with their filename. |

**Response `200`**

Returns [File](/reference/objects/file).

```json
{
  "id": "file_0193b8f2c1a87d3e9f4a",
  "object": "file",
  "livemode": false,
  "purpose": "business_logo",
  "filename": "logo.png",
  "size": 18432,
  "type": "png",
  "status": "available",
  "url": "https://cloud.oxy.so/assets/0193b8f2c1a87d3e9f4b",
  "created": 1793750400
}
```

Errors answer the error envelope with the HTTP status and `error.type` of the failure ([error codes](/errors)).

## Download a file's contents

`GET /v1/files/{id}/contents`

The bytes of a file you read back — a report run's CSV — as an attachment. Any other purpose answers 404: evidence and identity documents leave Peable only to their provider.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:read`
- **SDK:** `peable.files.contents()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `id` **required** | path | string | The file (`file_…`). |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Response `200`**

The bytes, as `text/csv`.
