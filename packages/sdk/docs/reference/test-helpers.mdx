## Expire a test-mode Checkout Session now

`POST /v1/test_helpers/checkout_sessions/{id}/expire`

A session nobody confirmed expires on its own deadline; one around a payment expires with that payment, in the same transition.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.testHelpers.checkoutSessions.expire()`
- **Mode:** Test mode only: a live credential is refused with [`test_mode_only`](/errors#test_mode_only).

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `id` **required** | path | string | The Checkout Session (`cs_…`). |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

## Simulate a FairCoin payment

`POST /v1/test_helpers/payment_intents/{id}/simulate_faircoin_payment`

Pretend the payer broadcast and the chain confirmed (or underpaid) a FairCoin payment in `requires_action`. A live credential is refused with 403 `test_mode_only`.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.testHelpers.paymentIntents.simulateFaircoinPayment()`
- **Mode:** Test mode only: a live credential is refused with [`test_mode_only`](/errors#test_mode_only).

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `id` **required** | path | string | The payment intent (`pi_…`). |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `outcome` | string | `settled` (the default): paid in full, seen and confirmed. `underpaid`: less than the amount arrived. |

**Response `200`**
