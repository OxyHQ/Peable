## Create a report run

`POST /v1/reporting/report_runs`

Answers `pending` at once; the CSV is produced in the background and announced with `reporting.report_run.succeeded` (or `.failed`).

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:read`
- **SDK:** `peable.reporting.reportRuns.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `report_type` **required** | string | One of `payments.itemized.1`, `balance.summary.1`, `balance_transactions.itemized.1`, `payouts.itemized.1`, `refunds.itemized.1`, `disputes.itemized.1`. |
| `parameters` **required** | object |  |
| `parameters[interval_start]` **required** | integer | Inclusive, Unix seconds. Between 0 and 253402300799. |
| `parameters[interval_end]` **required** | integer | Exclusive, Unix seconds; after `interval_start` and not in the future. Between 0 and 253402300799. |
| `parameters[columns]` | array of string | Columns of the report type's layout, each once. At most 64 items. At least 1 item. |
| `parameters[currency]` | string | One of `FAIR`, `EUR`, `USD`, `GBP`, `CHF`, `SEK`, `NOK`, `DKK`, `PLN`, `CZK`, `CAD`, `AUD`, `JPY`. |

## Create a report schedule

`POST /v1/reporting/report_schedules`

A report run at local midnight in `timezone` every day, week or month, each over the time since the previous occurrence. `next_run_at` is the first occurrence after now; nothing is backfilled.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.reporting.reportSchedules.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `report_type` **required** | string | One of `payments.itemized.1`, `balance.summary.1`, `balance_transactions.itemized.1`, `payouts.itemized.1`, `refunds.itemized.1`, `disputes.itemized.1`. |
| `parameters` | object |  |
| `parameters[columns]` | array of string | Columns of the report type's layout, each once. At most 64 items. At least 1 item. |
| `parameters[currency]` | string | One of `FAIR`, `EUR`, `USD`, `GBP`, `CHF`, `SEK`, `NOK`, `DKK`, `PLN`, `CZK`, `CAD`, `AUD`, `JPY`. |
| `schedule` **required** | object |  |
| `schedule[interval]` **required** | string | One of `daily`, `weekly`, `monthly`. |
| `schedule[weekly_anchor]` | string | Required for `weekly`, refused otherwise. One of `monday`, `tuesday`, `wednesday`, `thursday`, `friday`, `saturday`, `sunday`. |
| `schedule[monthly_anchor]` | integer | Required for `monthly`, refused otherwise; a shorter month fires on its last day. Between 1 and 31. |
| `timezone` | string | An IANA time zone (`Europe/Madrid`); `UTC` when absent. 1–64 characters. |
| `recipients` | array of string (email) | At most 10 addresses, each once. They receive a link to the run in Orbit, never the file. At most 10 items. |

## Download a report

`GET /v1/reporting/report_types/{id}/csv`

The same report a run produces, with the same parameters, streamed at once as CSV instead of stored. Every refusal is the JSON error before the first byte; a read that fails afterwards aborts the response, so a truncated file never ends cleanly.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:read`
- **SDK:** `peable.reporting.reportTypes.download()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `id` **required** | path | string | The report type (`payments.itemized.1`, …). |
| `interval_start` **required** | query | integer | Inclusive, Unix seconds. |
| `interval_end` **required** | query | integer | Exclusive, Unix seconds. |
| `columns[]` | query | array of string | Columns of the report type's layout, each once. At most 64 items. At least 1 item. |
| `currency` | query | string | One of `FAIR`, `EUR`, `USD`, `GBP`, `CHF`, `SEK`, `NOK`, `DKK`, `PLN`, `CZK`, `CAD`, `AUD`, `JPY`. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Response `200`**

The bytes, as `text/csv`.

Errors answer the error envelope with the HTTP status and `error.type` of the failure ([error codes](/errors)).
