## List webhook deliveries

`GET /v1/webhook_deliveries`

The delivery log, newest first: one event's deliveries, or one endpoint's. Both filters are public ids resolved inside your scope.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:read`
- **SDK:** `peable.webhookDeliveries.list()`

## Redeliver a webhook delivery

`POST /v1/webhook_deliveries/{id}/redeliver`

Send the delivery's event to its endpoint again — the SAME stored event, as a NEW delivery, attempted at once; answers that new delivery. Refused while the endpoint is disabled (`webhook_endpoint_disabled`).

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.webhookDeliveries.redeliver()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `id` **required** | path | string | The webhook delivery. |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Response `200`**

Returns [WebhookDelivery](/reference/objects/webhook-delivery).
