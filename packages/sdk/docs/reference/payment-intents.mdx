## Create a payment intent

`POST /v1/payment_intents`

`Idempotency-Key` also keys the intent itself: a key replayed after the 24-hour window answers 200 with the payment it created. On the card rail the answer carries `client_action`, the payer's next step.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.paymentIntents.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

## Retrieve a card payment's client action

`POST /v1/payment_intents/{id}/client_action`

What the payer's client must do next, to RESUME a card payment rather than create a second one. The merchant credential, or the payer's `client_secret` (`X-Peable-Client-Secret`). A POST so the credential never reaches a URL; answered `Cache-Control: no-store`. A FairCoin payment is a 400 (it is paid by sending coins to `next_action.faircoin_payment.address`); a payment that can no longer be paid is a 409.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:read`
- **SDK:** `peable.paymentIntents.clientAction()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `id` **required** | path | string | The payment intent (`pi_…`). |
| `client_secret` | query | string | Without a service credential: the object's `client_secret` (prefer the `X-Peable-Client-Secret` header). |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Response `200`**

Returns [ClientAction](/reference/objects/client-action).

Errors answer the error envelope with the HTTP status and `error.type` of the failure ([error codes](/errors)).
