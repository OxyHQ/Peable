| `query` **required** | query | string | Stripe's search query language: `email:"jenny@example.com"`, `amount>1000 AND currency:"EUR"`, `metadata['order_id']:'6735'`, `name~"shirt"`, `-status:"canceled"`, `customer:null`. 1–1000 characters. |
| `limit` | query | integer | Between 1 and 100. Default `10`. |
| `page` | query | string | The `next_page` of the previous page, with the SAME query. 1–512 characters. |
| `expand[]` | query | array of string | Dot paths of references to replace with the objects they name (at most four levels; `data.`-prefixed on a list). At most 20 items. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Response `200`**

A search result (`object: "search_result"`) whose `data` holds [Subscription](/reference/objects/subscription) objects, newest first.

| Field | Type | Description |
| --- | --- | --- |
| `object` | `"search_result"` |  |
| `data` | array of [Subscription](/reference/objects/subscription) |  |
| `has_more` | boolean |  |
| `next_page` | string \| null | Pass as `page` for the next page; `null` on the last one. |
| `url` | string | The path that was searched. |
| `total_count` | integer | Present only when asked for with `expand[]=total_count`. |
