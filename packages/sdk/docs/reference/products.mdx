## Create a product

`POST /v1/products`

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.products.create()`

| `images` | array of string | At most 8 items. |
| `metadata` | map of string | At most 50 keys; keys ≤ 40 characters, values ≤ 500. |

| `default_price_data` | object | Create the product's default price with it. |
| `default_price_data[currency]` **required** | string | Uppercase ISO 4217 code, or `FAIR`. One of `FAIR`, `EUR`, `USD`, `GBP`, `CHF`, `SEK`, `NOK`, `DKK`, `PLN`, `CZK`, `CAD`, `AUD`, `JPY`. |
| `default_price_data[unit_amount]` **required** | string | Base units of the currency, as an integer string (`"1999"` is 19.99 EUR). |
