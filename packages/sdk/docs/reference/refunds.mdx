## Create a refund

`POST /v1/refunds`

`external_ref` decides whether money moves twice: a retry with the same ref answers the refund it made (200) whatever is still refundable.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.refunds.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `payment_intent` **required** | string | The `pi_…` being refunded. |
| `external_ref` **required** | string | YOUR id for this refund. The idempotency: the same ref answers the same refund. 1–255 characters. |
| `amount` **required** | string | Base units, as a canonical integer string. Zero is refused. |
| `reason` | string | One of `duplicate`, `fraudulent`, `requested_by_customer`. |
| `metadata` | map of string | At most 50 keys; keys ≤ 40 characters, values ≤ 500. |
| `refund_application_fee` | boolean | Also refund Orbit's application fee, in proportion (a destination charge). |
| `reverse_transfer` | boolean | Also reverse the transfer to the destination account, in proportion. |

**Response `201`**

Returns [Refund](/reference/objects/refund).
