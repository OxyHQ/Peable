## Record a meter event

`POST /v1/billing/meter_events`

The customer must be yours and the value a non-negative integer. A repeated `identifier` answers the stored event.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.billing.meterEvents.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `event_name` **required** | string | Matches `^[A-Za-z0-9_.:-]{1,100}$`. |
| `payload` **required** | map of string |  |
| `identifier` | string | Default: a fresh one — pass your own so a retry is not counted twice. 1–100 characters. |
| `timestamp` | integer | Default now. At most 35 days in the past, 5 minutes in the future. Between 0 and 253402300799. |

**Response `200`**

Returns [BillingMeterEvent](/reference/objects/billing-meter-event).

```json

  "livemode": false,
  "identifier": "req_8f3a2c",
  "event_name": "api_call",
  "payload": {
    "peable_customer_id": "cus_0193b8f2c1a87d3e9f4a",
    "value": "25"
  },
  "timestamp": 1793750400,
  "created": 1793750400
}
```
