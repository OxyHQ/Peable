## Reserve an address to pay a person

`POST /v1/social/{username}/next_address`

A fresh address of the recipient's, derived from their Oxy identity key. Limited per (sender, recipient) pair; a recipient without an identity answers 409 `keyless_recipient`; paying yourself is refused.

- **Authentication:** [Oxy user session](/reference#oxy-user-session)

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `username` **required** | path | string | The recipient’s Oxy username. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `network` **required** | string | One of `mainnet`, `testnet`. |
| `source` | object |  |
| `source[app]` **required** | string | 1–32 characters. Matches `^[a-z0-9][a-z0-9._-]*$`. |
| `source[ref]` | string | 1–128 characters. Matches `^[\x21-\x7e]+$`. |

**Response `200`**

Returns [SocialNextAddress](/reference/objects/social-next-address).

Errors answer the error envelope with the HTTP status and `error.type` of the failure ([error codes](/errors)).
