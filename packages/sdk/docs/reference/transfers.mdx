## Create a transfer

`POST /v1/transfers`

Settles one seller out of a funded payment (201). An order already settled answers the stored settlement (200): a merchant retrying after a timeout needs to know whether they just paid a seller twice.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.transfers.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `payment_intent` **required** | string | The `pi_…` this settles out of. |
| `connected_account` | string | The seller's `ca_…`. |
| `connected_account_ref` | string | Or your own id for the seller (its `external_ref`). 1–255 characters. |
| `external_ref` **required** | string | Your own id for what this settles — the idempotency: the same ref answers the stored settlement (200), a different payment or amount under it is a 409. 1–255 characters. |
| `amount` **required** | string |  |
