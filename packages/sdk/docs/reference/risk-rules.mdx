## Create a risk rule

`POST /v1/radar/rules`

Parsed and checked against the fact registry: a predicate that does not parse is a 400 with `param: predicate` and the position.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.radar.rules.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `action` **required** | string | One of `allow`, `block`, `review`. |
| `predicate` **required** | string | Radar's language over the fact registry; see the risk rules guide. 1–1000 characters. |
| `description` | string | 1–500 characters. |
| `enabled` | boolean | Default `true`. |
| `expand` | array of string | Dot paths of references to replace with the objects they name (at most four levels; `data.`-prefixed on a list). At most 20 items. |

**Response `200`**

Returns [RadarRule](/reference/objects/radar-rule).

```json
{
  "id": "rule_0193b8f2c1a87d3e9f4a",
  "object": "radar.rule",
  "livemode": false,
  "action": "block",
  "predicate": ":currency: = 'EUR' and :amount: > 100000 and :card_country: not in ('ES', 'FR')",
  "description": "Large euro payments from cards issued outside our markets",
  "enabled": true,
  "version": 1,
  "created": 1793750400,
  "updated": 1793750400
}
```
