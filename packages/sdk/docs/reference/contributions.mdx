## Create a contribution link

`POST /v1/organizations/{organizationId}/applications/{applicationId}/contributions`

Requires a UUID `Idempotency-Key` header: the operation key, so a retry after a lost answer returns the same link.

- **Authentication:** [Oxy user session](/reference#oxy-user-session)

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `organizationId` **required** | path | string | The Oxy organization. |
| `applicationId` **required** | path | string | The organization's Oxy application whose merchant collects. |
| `environment` **required** | query | string | Which of the application's merchants: its Test/Live toggle. One of `development`, `staging`, `production`. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `purpose` **required** | string | 1–500 characters. |
| `amount_mode` **required** | string | `fixed`: the link names the amount; `free`: the payer chooses it. |
| `amount` | string | Matches `^[1-9][0-9]{0,15}$`. |
| `currency` **required** | `"FAIR"` |  |
| `expires_at` | integer \| null |  |

**Response `201`**

Returns [ContributionLink](/reference/objects/contribution-link).
