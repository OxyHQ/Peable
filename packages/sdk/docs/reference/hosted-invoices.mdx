## Pay a hosted invoice

`POST /v1/invoices/public/{token}/pay`

The PaymentIntent the payer completes in the method they chose — a card through the provider’s own fields, or FairCoin from the payer’s wallet (quoted on a fiat invoice, ADR 0021). The same invoice answers the same intent while it can still be paid in that method.

- **Authentication:** None. A payer-facing route, authorised by the unguessable id or client secret it is called with.

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `token` **required** | path | string | The hosted invoice token (from `hosted_invoice_url`). |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `payment_method_type` | string | One of the invoice's `payment_method_types`. Default: the rail of its currency (`card` on a fiat invoice). `faircoin` on a fiat invoice quotes the amount due in FAIR for 10 minutes; paying again with the other method replaces a payment that has not started moving money. |

**Response `200`**

Returns [PublicInvoicePayment](/reference/objects/public-invoice-payment).
