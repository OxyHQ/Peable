## List request logs

`GET /v1/request_logs`

Your API requests of the last 30 days, newest first, filtered by `status`, `method` and `created`.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:read`
- **SDK:** `peable.requestLogs.list()`

| `ending_before` | query | string | The id of the FIRST object of the current page: the page returned is newer. 1–255 characters. |
| `created` | query | integer \| object | Unix seconds: exactly one second, or a range with `gt`, `gte`, `lt`, `lte`. |

## Stream request logs

`GET /v1/request_logs/stream`

Server-Sent Events: each request as it is answered (`event: request_log`), after a `ready` event. Reconnect with `Last-Event-ID` to resume without a gap. Test mode only; a stream ends after 15 minutes.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:read`
- **SDK:** `peable.requestLogs.stream()`
- **Mode:** Test mode only: a live credential is refused with [`test_mode_only`](/errors#test_mode_only).

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `status` | query | integer \| string | One status code (`404`) or a class (`2xx`, `3xx`, `4xx`, `5xx`). Between 100 and 599. |
| `method` | query | string | One of `GET`, `POST`, `DELETE`, `PATCH`, `PUT`. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Response `200`**

A Server-Sent Events stream (`text/event-stream`); each event's `data` is [RequestLog](/reference/objects/request-log).

Errors answer the error envelope with the HTTP status and `error.type` of the failure ([error codes](/errors)).
