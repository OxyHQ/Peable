## Create a connection token

`POST /v1/terminal/connection_tokens`

A fresh token on every call, limited to one of your locations (unlike Stripe, `location` is required), answered with `Cache-Control: no-store` and never stored or replayed (no `Idempotency-Key` replay: a token is a credential, and minting two moves nothing). 503 `terminal_unavailable` when Terminal is not enabled in this mode.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.terminal.connectionTokens.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `location` **required** | string | The location (`tml_…`) whose readers the token may reach. Required: readers live on one provider account shared by every merchant, and a token without a location would reach all of them. 1–255 characters. |

**Response `201`**

Returns [TerminalConnectionToken](/reference/objects/terminal-connection-token).

Errors answer the error envelope with the HTTP status and `error.type` of the failure ([error codes](/errors)).

## Collect a PaymentIntent on a reader

`POST /v1/terminal/readers/{id}/process_payment_intent`

The reader asks the cardholder to tap, insert or swipe. Answers the reader with its action `in_progress`; the outcome arrives as `terminal.reader.action_succeeded` or `…action_failed`, and the PaymentIntent moves through its own events. A declined card leaves it `requires_payment_method` with `last_payment_error`, collectable again. 409 `terminal_reader_busy` or `terminal_reader_offline` when the reader cannot take it.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.terminal.readers.processPaymentIntent()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `id` **required** | path | string | The reader (`tmr_…`). |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `payment_intent` **required** | string | A `card_present` PaymentIntent (`pi_…`) of this merchant that is still waiting for a payment method. 1–255 characters. |
| `process_config` | object |  |
