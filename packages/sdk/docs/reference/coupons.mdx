## Create a coupon

`POST /v1/coupons`

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.coupons.create()`

| Name | In | Type | Description |

| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Your own id (`SUMMER25`); generated (`coupon_…`) when absent. Matches `^[A-Za-z0-9_-]{1,64}$`. |
| `name` | string | 1–40 characters. |
| `percent_off` | number | At most 100. |
| `amount_off` | string | Base units of the currency, as an integer string (`"1999"` is 19.99 EUR). |
| `currency` | string | Uppercase ISO 4217 code, or `FAIR`. One of `FAIR`, `EUR`, `USD`, `GBP`, `CHF`, `SEK`, `NOK`, `DKK`, `PLN`, `CZK`, `CAD`, `AUD`, `JPY`. |
| `duration` | string | Default `once`. One of `once`, `repeating`, `forever`. |
| `duration_in_months` | integer | Required for `repeating`. Between 1 and 1200. |
| `max_redemptions` | integer | Between 1 and 2147483647. |
| `redeem_by` | integer | Unix seconds, in the future. At most 253402300799. |
