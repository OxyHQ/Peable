## Recover a checkout operation

`GET /v1/billing/checkout_operations/{key}`

Reads the state of a checkout attempted under this `Idempotency-Key`, even after its quote or session expired. Missing, pending or indeterminate never authorizes another create or a cancellation.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:read`
- **SDK:** `peable.billing.retrieveCheckoutOperation()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `key` **required** | path | string | The `Idempotency-Key` the checkout was created with. |
| `provider_customer_id` **required** | query | string | 1–128 characters. Matches `^[A-Za-z0-9_.:-]+$`. |
| `provider_price_id` **required** | query | string | 1–128 characters. Matches `^[A-Za-z0-9_.:-]+$`. |
| `store_id` **required** | query | string | 1–128 characters. Matches `^[A-Za-z0-9_.:-]+$`. |
| `plan_id` **required** | query | string | 1–128 characters. Matches `^[A-Za-z0-9_.:-]+$`. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Response `200`**

Returns [BillingCheckoutOperationRecovery](/reference/objects/billing-checkout-operation-recovery).

## Create a subscription checkout

`POST /v1/billing/checkout_sessions`

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.billing.createCheckoutSession()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `rail` | string | A settlement rail: `stripe`, `faircoin`, or a further fiat provider. Matches `^[a-z][a-z0-9_]{1,31}$`. |
| `provider_customer_id` **required** | string | At most 128 characters. Matches `^cus_[A-Za-z0-9]+$`. |
| `provider_price_id` **required** | string | At most 128 characters. Matches `^price_[A-Za-z0-9]+$`. |
| `trial_days` **required** | integer | Between 0 and 730. |

| `return_url` **required** | string (uri) | At most 2048 characters. |
| `store_id` **required** | string | 1–128 characters. Matches `^[A-Za-z0-9_.:-]+$`. |
| `plan_id` **required** | string | 1–128 characters. Matches `^[A-Za-z0-9_.:-]+$`. |
