## Create a webhook endpoint

`POST /v1/webhook_endpoints`

The answer is the ONLY one that shows `secret`. A retry with the same `Idempotency-Key` replays it, secret included, for 24 hours. At most 16 endpoints per merchant and mode.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.webhookEndpoints.create()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `url` **required** | string | An `https` URL (a test-mode endpoint may also use `http`), ports 80/443 only. |
| `enabled_events` **required** | array of string | At most 93 items. At least 1 item. |
| `description` | string | 1–5000 characters. |
| `metadata` | map of string | At most 50 keys; keys ≤ 40 characters, values ≤ 500. |

**Response `200`**

Returns [WebhookEndpointWithSecret](/reference/objects/webhook-endpoint-with-secret).


## Roll the signing secret

`POST /v1/webhook_endpoints/{id}/roll_secret`

Mint a new secret and show it once. With `expires_in_seconds` (≤ 24h) the previous one keeps signing beside it until then; without, it stops now.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.webhookEndpoints.rollSecret()`

**Parameters**

| Name | In | Type | Description |

| `id` **required** | path | string | The webhook endpoint (`we_…`). |
| `Idempotency-Key` | header | string | Makes a retry safe: the same key with the same request answers the stored response for 24 hours (ADR 0014 D3). The SDK sends one on every POST. At most 255 characters. |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `expires_in_seconds` | integer | How long the PREVIOUS secret keeps signing beside the new one, in seconds (0–86400, default 0). While both are live every delivery carries two `v1=` signatures, so a receiver can switch secrets without a gap. Between 0 and 86400. |
