## Register the merchant

`POST /v1/merchants`

Registers the calling application's merchant in the credential's environment. A non-production credential can register a testnet merchant only. A second registration for the same application and environment answers 409. Outside the generic idempotency layer: the merchant is the scope it keys on.

- **Authentication:** [Oxy service token (EdDSA JWT)](/reference#oxy-service-token-eddsa-jwt)
- **Scope:** `payments:write`
- **SDK:** `peable.merchants.register()`

**Parameters**

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `Peable-Version` | header | string | The wire date the caller was written against. Only `2026-11-03` exists. |

**Request body** (`application/json`)

| Field | Type | Description |
| --- | --- | --- |
| `required_confirmations` | integer | Confirmations a FairCoin payment needs to succeed. Defaults to 6 for a live (mainnet) merchant, 1 on testnet. |
| `display_name` | string | 1–64 characters. |
| `avatar_file_id` | string | 1–128 characters. |
| `description` | string | 1–512 characters. |

**Response `201`**

Returns [Merchant](/reference/objects/merchant).

```json

  "object": "merchant",
  "livemode": false,

  "environment": "development",
  "network": "testnet",
  "owner_account": "0193b8f2-c1a8-7d3e-9f4a-5b6c7d8e9f01",
```
