# ConnectedAccount

## Attributes

| Field | Type | Description |
| --- | --- | --- |
| `id` | string |  |
| `object` | `"connected_account"` |  |
| `livemode` | boolean | `true` in live mode, `false` in test mode. |
| `external_ref` | string | The merchant's OWN id for this seller — how they address it. |
| `rails` | array of string | Which halves this account has. Never empty. |
| `faircoin` | [ConnectedAccountFaircoin](/reference/objects/connected-account-faircoin) \| null | The FairCoin half, or `null` when the platform never opened one. Readiness for FairCoin is `faircoin.status === 'active'`; `payable` is about the CARD half. |
| `country` | string \| null | ISO 3166-1 alpha-2, upper-case. `null` on a FairCoin-only seller, which has no card half. |
| `default_currency` | string \| null |  |
| `payable` | boolean | Whether this seller can receive a CARD settlement (a transfer) right now. A convenience: every field it is derived from is here too. Always `false` on a FairCoin-only seller. |

| `charges_enabled` | boolean |  |
| `transfers_capability` | string \| null | `null`: never requested — a different fact from the provider declining it. One of `active`, `pending`, `inactive`. |
| `card_payments_capability` | string \| null | One of `active`, `pending`, `inactive`. |
| `requirements` | [AccountRequirements](/reference/objects/account-requirements) |  |
