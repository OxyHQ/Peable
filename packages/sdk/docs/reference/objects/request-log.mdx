# RequestLog

Object type: `request_log`.

## Attributes

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | The request's `Request-Id` (`req_…`). |
| `object` | `"request_log"` |  |
| `livemode` | boolean | `true` in live mode, `false` in test mode. |
| `method` | string | One of `GET`, `POST`, `DELETE`, `PATCH`, `PUT`. |
| `path` | string | The path that was requested, without its query string. |
| `status` | integer | The HTTP status it was answered with. At least -9007199254740991. |
| `duration_ms` | integer | How long the gateway took to answer, in milliseconds. |
