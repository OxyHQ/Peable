# Balance

Object type: `balance`.

## Attributes

| Field | Type | Description |
| --- | --- | --- |
| `object` | `"balance"` |  |
| `livemode` | boolean | `true` in live mode, `false` in test mode. |
| `available` | array of [BalanceAmount](/reference/objects/balance-amount) | Payable now: the provider has made these funds available. |
| `pending` | array of [BalanceAmount](/reference/objects/balance-amount) | Not yet available at the provider. |
| `informational` | array of [BalanceAmount](/reference/objects/balance-amount) | FairCoin received straight into the merchant's own wallet (ADR 0015 §5): recorded for the books only. Orbit never held it, so it is never payable. |
| `account` | string \| null | The account (`ca_…`) this balance mirrors; `null` for an Oxy first-party merchant. |
