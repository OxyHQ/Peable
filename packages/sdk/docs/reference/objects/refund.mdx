| Field | Type | Description |

| `livemode` | boolean | `true` in live mode, `false` in test mode. |
| `external_ref` | string \| null | YOUR id for this refund (its idempotency); `null` on a refund imported from the provider (`origin: 'provider'`). |

| `currency` | string | Uppercase ISO 4217 code, or `FAIR`. One of `FAIR`, `EUR`, `USD`, `GBP`, `CHF`, `SEK`, `NOK`, `DKK`, `PLN`, `CZK`, `CAD`, `AUD`, `JPY`. |
| `status` | string | The MONEY's own lifecycle: a bank can reject a refund days later (`failed`); `canceled` only through `POST /v1/refunds/{id}/cancel`. One of `pending`, `succeeded`, `failed`, `canceled`. |
