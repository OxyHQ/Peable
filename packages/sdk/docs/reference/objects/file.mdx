# File

Object type: `file`.

## Attributes

| Field | Type | Description |
| --- | --- | --- |
| `id` | string |  |
| `object` | `"file"` |  |
| `livemode` | boolean | `true` in live mode, `false` in test mode. |
| `purpose` | string | One of `dispute_evidence`, `business_logo`, `identity_document`, `additional_verification`, `finance_report_run`, `tax_document`. |
| `filename` | string \| null | The name it was uploaded with, if it had a printable one. |
| `size` | integer | Bytes. |
| `type` | string | One of `pdf`, `png`, `jpg`, `csv`. |
| `status` | string | One of `available`, `withheld`, `removed`. |
| `url` | string \| null | Where the bytes can be read while the file is `available`: a public URL for a `business_logo`, `GET /v1/files/{id}/contents` for a `finance_report_run`. `null` for every other purpose — evidence and identity documents are never addressable by URL. |
| `created` | integer | Unix seconds. |
