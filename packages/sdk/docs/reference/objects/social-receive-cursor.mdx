# SocialReceiveCursor

## Attributes

| Field | Type | Description |
| --- | --- | --- |

| `identity_public_key` | string \| null | The identity public key (hex) those addresses derive from — the key recorded at the LAST reservation; `null` exactly when no address was ever reserved. |
