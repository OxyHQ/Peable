# Coupon

Object type: `coupon`.

## Attributes

| Field | Type | Description |
| --- | --- | --- |
| `id` | string |  |
| `object` | `"coupon"` |  |
| `livemode` | boolean | `true` in live mode, `false` in test mode. |
| `name` | string \| null |  |
| `percent_off` | number \| null | 0 &lt; x ≤ 100, at most two decimals. Set exactly when `amount_off` is not. |
| `amount_off` | string \| null | Base units taken off, in `currency`. Matches `^(0\|[1-9][0-9]*)$`. |
| `currency` | string \| null | Uppercase ISO 4217 code, or `FAIR`. One of `FAIR`, `EUR`, `USD`, `GBP`, `CHF`, `SEK`, `NOK`, `DKK`, `PLN`, `CZK`, `CAD`, `AUD`, `JPY`. |
| `duration` | string | One of `once`, `repeating`, `forever`. |
| `duration_in_months` | integer \| null | Months a `repeating` coupon lasts; `null` otherwise. At least -9007199254740991. |
| `max_redemptions` | integer \| null | At least -9007199254740991. |
| `redeem_by` | integer \| null | The last instant it can be redeemed. |
| `times_redeemed` | integer | At least -9007199254740991. |
| `valid` | boolean | Whether it can still be redeemed: not past `redeem_by` and not used up. |
| `applies_to` | object \| null | The products (`prod_…`) it is restricted to, or `null` for every product. |
| `applies_to.products` | array of string |  |
