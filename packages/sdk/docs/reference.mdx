# API reference

The Peable payments API (Orbit): FairCoin and card payments, Checkout, Payment Links, Billing, Connect and Tax. Amounts are base-unit integer strings; instants are Unix seconds; every object carries `id`, `object` and `livemode`. Guides: https://oxy.so/developers/docs/peable/.

Version `2026-11-03` of the Peable API (OpenAPI 3.1.0), sent as `Peable-Version` on every answer. Every page here is generated from the [OpenAPI document](https://github.com/OxyHQ/Peable/blob/main/docs/openapi.json), which is generated from the route contracts the gateway validates with, so the reference and the API cannot disagree.

## Authentication

Every request carries `Authorization: Bearer <token>`. Each operation names the token it takes; routes with none are payer-facing. Credentials are in the [quickstart](/quickstart).

### Oxy service token (EdDSA JWT)

`oxyServiceToken`: http bearer. Your server's Oxy service token, minted from its application credential. `@peable.to/sdk` mints and refreshes it for you.

### Oxy user session

`oxyUserSession`: http bearer. A signed-in Oxy user (the Peable app, an Oxy app acting for its user).
